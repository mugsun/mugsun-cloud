# 自检的最后一步（smoke-sweep.py roleless）拿这份清单和实际核对，多一个、少一个都不通过。
#
# 「进得去」指请求没有被权限拦在外面，也就是返回的不是 403。进去以后接口自己还会校验，
# 比如只给这个人自己的数据，或者要他是这条待办的办理人。那一层这里不查。

# 自检报「比清单多出」时不要直接照着补。/system 下的写接口（POST、PUT、DELETE）没写权限码时另有一道兜底，
