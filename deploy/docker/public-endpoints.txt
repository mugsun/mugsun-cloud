# 不用登录就能访问的接口，一行一个：方法 路径。自检的最后一步（smoke-sweep.py）拿它核对：
# 四个服务的接口文档里，路径落在免登录名单（LoginPublicPaths）里的接口，必须和这里一模一样。
#
# 自检报「多出」：先确认这个接口确实该对没登录的人开放，再把那一行加进来。公开接口属于敏感改动。
#   名单里有几段是按前缀算的（/open、/v1、/file、/track 等），它们下面新加一个接口，就自动不用登录。
# 自检报「现在不是不用登录的」：这个接口被删掉了，或者现在要登录了，把那一行删掉。
#
# 这里只有接口文档里的接口。健康检查、静态文件这类不在文档里的路径不在这里。
# 「不用登录」只是说不查登录令牌。下面按「为什么开放」分了组，有的组另有自己的一道校验，
# 自检不查那道校验，分组和顺序也不影响核对。
